# adiya-tv

FragBoard — CS2-ийн HLTV болон Valve (VRS) рэнк, тэмцээн, баг, тоглогч, шууд тоглолт, мэдээг монголоор харуулдаг вэб сайт.

## Бүтэц
- `index.html` — бүх хуудас (рэнкинг, тэмцээн, баг, тоглогч, шууд тоглолтын онооны самбар/лог/радар, мэдээ)
- `hltv-data.js` — рэнк, баг, тоглогч, тэмцээний өгөгдөл ба лого/зураг/туг/радар (2026-10-15)
- `supabase/` — шууд өгөгдлийн жижиг хүснэгт (`public.live`), realtime-тай

## Ажиллуулах
`index.html`-ийг браузерт нээх эсвэл ямар нэг статик хостинг (GitHub Pages, Vercel, Netlify) дээр байршуулна.

Өгөгдлийн эх сурвалж: HLTV.org, Valve Regional Standings.
